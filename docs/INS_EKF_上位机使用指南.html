2. 接收数据（STM32 → PC）

2.1 协议：VOFA+ JustFloat

每帧由 36 个 float（little-endian） + 4 字节帧尾组成：

[float_0][float_1]...[float_35][0x00][0x00][0x80][0x7F]

总字节数：36 × 4 + 4 = 148 字节/帧

使用方式：打开 VOFA+ 软件，选择 JustFloat 协议，连接对应串口即可实时显示波形。

3. 发送参数（PC → STM32）

3.1 帧格式

[0xA5][0x5A][CMD][LEN_L][LEN_H][PAYLOAD...][CRC_L][CRC_H][0x5A][0xA5]
字段长度说明
帧头2 B固定 0xA5 0x5A
CMD1 B命令字
LEN2 BPayload 字节数，little-endian
PAYLOADLEN B参数数据
CRC162 Blittle-endian，校验范围见下
帧尾2 B固定 0x5A 0xA5
CRC16 校验范围：CMD + LEN_L + LEN_H + PAYLOAD（不含帧头和帧尾）。
算法：CRC-16（初始值 0x0000），具体查表实现参考工程中 modules/algorithm/crc16.c。

3.2 命令字定义

CMD名称Payload 长度说明
0x01设置参数78 B下发全部参数，立即生效
0x02查询参数0 BSTM32 在下一帧 VOFA 中反映当前值

def crc16(data: bytes) -> int:
    crc = 0x0000
    for b in data:
        crc = (crc >> 8) ^ CRC16_TABLE[(crc ^ b) & 0xFF]
    return crc

def build_frame(cmd: int, payload: bytes = b'') -> bytes:
    head = bytes([0xA5, 0x5A])
    body = bytes([cmd]) + struct.pack('<H', len(payload)) + payload
    crc_val = crc16(body)
    tail = bytes([0x5A, 0xA5])
    return head + body + struct.pack('<H', crc_val) + tail

5. 错误码（CH35）

值含义
0无错误
1Payload 长度不匹配（应为 78 字节）
2参数值非法（sanitize 失败）
3未知 CMD

6. 快速调参流程

  1. 连接 UART6，打开 VOFA+ 选择 JustFloat 协议，确认能看到波形
  2. 观察 CH6~CH9（Q1/Q2/R/lambda 当前生效值）和 CH0（Yaw）
  3. 用 Python 脚本修改目标参数，通过 CMD=0x01 下发
  4. 观察 CH14~CH17 确认参数已更新，观察 CH35 确认错误码为 0
  5. 反复调整直到 Yaw 漂移和姿态响应满意
